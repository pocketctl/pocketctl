安装

一键安装（推荐）

curl -fsSL https://pocketctl.com/install.sh | bash

手动安装

# 从 GitHub Releases 下载对应平台的二进制
# macOS (Apple Silicon)
curl -L -o pocketctl https://github.com/pocketctl/pocketctl/releases/latest/download/pocketctl_darwin_arm64

# macOS (Intel)
curl -L -o pocketctl https://github.com/pocketctl/pocketctl/releases/latest/download/pocketctl_darwin_amd64

# Linux (x86_64)
curl -L -o pocketctl https://github.com/pocketctl/pocketctl/releases/latest/download/pocketctl_linux_amd64

# Linux (ARM64)
curl -L -o pocketctl https://github.com/pocketctl/pocketctl/releases/latest/download/pocketctl_linux_arm64

# 设置执行权限并移动到 PATH
chmod +x pocketctl
sudo mv pocketctl /usr/local/bin/

pocketctl login

📱 手机号登录
通过短信验证码登录，Token 自动保存到 ~/.pocketctl/auth.json
pocketctl login [--relay URL] [--prod]

参数说明

参数说明标签
--relay URL 指定 Relay 服务器地址 可选 默认: ws://localhost:8080/ws
--prod 连接生产环境 可选 默认: ws://39.106.218.47/ws

使用示例

# 连接本地测试环境（默认）
pocketctl login

# 连接生产环境
pocketctl login --prod

# 连接自定义 relay 服务器
pocketctl login --relay wss://your-server.com/ws

交互流程

$ pocketctl login

验证码: 000000
正在验证... 登录成功!
Token 已保存到 ~/.pocketctl/auth.json
现在可以运行 'pocketctl daemon start' 启动守护进程

pocketctl daemon start

🚀 启动守护进程
启动 daemon 连接到 Relay 服务器，监控本地 AI 编程会话
pocketctl daemon start [--relay URL] [--prod] [--token TOKEN] [--id DAEMON_ID]

参数说明

参数说明标签
--relay URL Relay 服务器地址 可选 默认读取已保存配置
--prod 连接生产环境 可选
--token TOKEN JWT 认证令牌 可选 默认读取已保存配置
--id DAEMON_ID 自定义 Daemon ID 可选 默认自动生成

Relay 地址解析优先级

优先级来源说明
1（最高）--relay 参数命令行直接指定
2POCKETCTL_RELAY_URL环境变量
3~/.pocketctl/auth.jsonlogin 时保存的地址
4--prod 标志使用生产环境地址
5（兜底）内置默认值生产环境地址

使用示例

# 使用已保存的配置启动（最常用）
pocketctl daemon start

# 连接本地测试环境
pocketctl daemon start --relay ws://localhost:8080/ws

# 连接生产环境
pocketctl daemon start --prod

# 使用自定义 token 启动
pocketctl daemon start --relay ws://localhost:8080/ws --token eyJhbG...

pocketctl daemon doctor

🩺 连接诊断
诊断连接和配置问题，检查 DNS、网络连通性、WebSocket、认证状态等
pocketctl daemon doctor

检查项

检查项说明
配置文件检查 ~/.pocketctl/auth.json 是否存在
认证令牌检查 Token 是否有效、是否过期
DNS 解析检查 Relay 域名能否正常解析
HTTP 连通检查与 Relay 的 HTTP 连接（延迟、状态码）
Relay 健康调用 /health 接口检查服务状态
WebSocket 连接测试 WebSocket 握手是否成功
认证通过验证 Token 能否通过 Relay 认证
Daemon 限制检查当前用户的 Daemon 数量限制

pocketctl daemon update

🔄 自更新
从 GitHub Releases 下载最新版本，自动替换并重启
pocketctl daemon update [--version TAG] [--no-restart]

参数说明

参数说明标签
--version TAG 指定升级到特定版本（如 v0.2.0） 可选 默认: latest
--no-restart 仅替换二进制，不重启 daemon 可选

更新流程

1查询最新版本
→
2下载二进制
→
3SHA256 校验
→
4替换二进制
→
5重启 Daemon

配置文件

认证信息保存在 ~/.pocketctl/auth.json：

{
  "relay_url": "ws://localhost:8080/ws",
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIs..."
}
字段说明
relay_urlRelay WebSocket 地址，由 login 命令保存
access_tokenJWT 访问令牌，有效期 24 小时
refresh_tokenJWT 刷新令牌，有效期 7 天
💡 提示
daemon start 会自动读取此文件中的 relay_url 和 access_token，无需手动指定。

App 环境切换

pocketctl iOS App 支持「生产环境」和「测试环境」切换，方便开发调试。

切换方式

打开 App → 设置页 → 顶部 「环境」开关，点击即可切换：

环境HTTP 地址WebSocket 地址用途
生产环境（默认） http://39.106.218.47 ws://39.106.218.47/ws 正式使用
测试环境 http://localhost:8080 ws://localhost:8080/ws 本地开发调试

本地测试流程

1启动本地 Relay
→
2App 切换测试环境
→
3App 登录测试账号
→
4daemon 连本地 Relay
# 1. 启动本地 Docker Relay
cd ~/project/pocketctl
docker compose up -d

# 2. 在 App 设置页切换到「测试环境」

# 3. App 使用测试手机号 13800138000 登录，验证码 000000

# 4. daemon 连接本地 Relay
pocketctl login                              # 登录本地环境
pocketctl daemon start --relay ws://localhost:8080/ws
⚠️ 注意
测试环境下只支持测试手机号 13800138000，验证码固定为 000000。不会发送真实短信。
💡 提示
在 iOS 模拟器中，localhost 会自动指向 Mac 本机，所以 Docker Relay 无需额外配置即可访问。

变量名说明示例

POCKETCTL_TOKEN JWT 认证令牌（优先级高于配置文件） eyJhbG...

常见问题

如何连接本地测试环境？

pocketctl login                              # 登录本地环境
pocketctl daemon start --relay ws://localhost:8080/ws

如何连接生产环境？

pocketctl login --prod                      # 登录生产环境
pocketctl daemon start                      # 使用已保存的配置启动

Token 过期了怎么办？

重新运行 pocketctl login 即可获取新的 Token。

如何检查 daemon 连接问题？

pocketctl daemon doctor

doctor 命令会逐项检查配置、网络、认证等，帮助定位问题。

更新时权限不足怎么办？

sudo pocketctl daemon update
⚠️ 注意
如果二进制安装在系统目录（如 /usr/local/bin/），需要 sudo 权限才能替换。
