A

服务端上线

Day 1 · 没有线上服务，iOS App 连不上

A1. 云服务器准备

  • 购买腾讯云/阿里云 ECS（2C4G 足够）
  • 安装 Docker + Docker Compose
  • 域名解析（如 relay.pocketctl.me）

A2. 生产环境配置

  • 创建 docker-compose.prod.yml
    • PostgreSQL 强密码
    • POCKETCTL_API_KEY 随机生成
    • ZHIPU_API_KEY 配置
    • 端口不对外暴露（只暴露 Nginx）
  • Nginx 反向代理 + WSS（WebSocket 升级 + 86400s 超时）
  • HTTPS 证书（Let's Encrypt / 腾讯云免费证书）

A3. 部署验证

  • docker compose up -d 启动服务
  • 验证 /health 端点返回 200
  • 验证 WSS 连接正常
  • Daemon 远程连接测试

预估 1 天

B

iOS App 上架准备

Day 2-4 · 最耗时——苹果审核需要各种材料

B1. Apple Developer 配置

  • Apple Developer Program（$99/年）
  • App ID（com.pocketctl.app）
  • APNs 推送证书
  • Provisioning Profile（Development + Distribution）

B2. App 功能完善

  • 登录/注册页面（当前是手动输入 token？）
  • Codex「即将开通」标签确认（苹果可能不允许）
  • 确保无 debug 日志、无测试数据
  • 空状态引导（未连接 Daemon 时的提示）
  • 错误处理（网络断开、token 过期）

B3. App Store Connect 配置

  • App 名称：pocketctl
  • 副标题：Your coding agents, in your pocket
  • 分类：开发者工具 / 效率
  • 截图：iPhone 6.7" + 6.1"（至少 3 张）
  • App Icon（已有 ✅）
  • 隐私政策 URL
  • 用户协议 URL
  • 描述文案

B4. 隐私与合规

  • 隐私政策页面（部署到公网）
  • 用户协议页面
  • App 隐私声明（App Store Connect 中填写）

预估 3 天（不含审核等待）

C

Daemon 分发

Day 5 · 用户需要能方便地安装 Daemon

C1. 安装脚本

  • 创建 install.sh 
    curl -fsSL https://pocketctl.me/install.sh | bash
  • 检测 OS/架构（macOS arm64/amd64, Linux）
  • 下载对应二进制到 /usr/local/bin/pocketctl
  • 部署到公网（Nginx 托管或 GitHub Pages）

C2. 文档

  • README 更新（安装方式、使用说明）
  • 快速开始指南

预估 1 天

D

提交审核 + 上线

Day 6-10 · TestFlight 测试 → 提交 → 等待审核

D1. TestFlight 测试

  • Archive → Upload to App Store Connect
  • TestFlight 内部测试（自己 + 1-2 个朋友）
  • 验证完整流程：注册→登录→安装 Daemon→创建会话→推送

D2. 提交审核

  • 填写审核信息（Demo 账号）
  • 提交 App Review
  • 等待审核（通常 1-3 天，首次可能更久）

D3. 上架后

  • 监控崩溃报告
  • 收集用户反馈
  • 准备第一版更新

预估 1 天操作 + 1-3 天审核等待

⚠️ 关键卡点

卡点影响建议
