云部署 + 用户体验优化

Week 1-2 · 目标：服务端部署到云上，公网可访问

1.1 生产环境部署

  • 创建 docker-compose.prod.yml（强密码、API Key、端口隔离）
  • 配置 HTTPS（Let's Encrypt / 已有证书）
  • WSS 代理配置（Nginx WebSocket 升级 + 86400s 长超时）
  • 安全加固：CORS 限制、关闭 debug 日志

改动文件： docker-compose.prod.yml（新建）、web/nginx.conf

1.2 Daemon 一键安装

  • 创建安装脚本 curl -fsSL https://pocketctl.com/install.sh | bash
  • Homebrew Formula：brew tap pocketctl/tap && brew install pocketctl
  • 版本号注入：Go build -ldflags "-X main.version=v0.1.0"

改动文件： scripts/install.sh（新建）、Makefile（新建）

1.3 Web UI 体验优化

  • 登录页（替代 localStorage 手动设 API Key）
  • Session 列表空状态引导（提示安装 Daemon）
  • 下拉刷新（移动端）
  • Session 详情加载骨架屏
  • 消息发送后自动滚到底部

改动文件： web/src/views/LoginView.vue（新建）、SessionList.vue、SessionDetail.vue

1.5

多代理支持

Week 3-5 · 目标：支持 Codex 和 OpenCode，与 Claude Code 并行工作

1.5.1 代理适配器架构重构

当前架构完全硬编码为 Claude Code，需要重构为可插拔的适配器模式。三个代理都支持 NDJSON 流式输出，可用统一接口处理。

代理CLI 无头模式流式 JSON会话恢复会话存储
Claude Codeclaude -p "..." --output-format stream-json✅--resume <id>~/.claude/sessions/ JSONL
Codexcodex exec --json "..."✅codex exec resume <id>~/.codex/sessions/ JSONL
OpenCodeopencode run --format json "..."✅--session <id>XDG_DATA_HOME/opencode/storage/ JSON
  • 定义 AgentAdapter 接口（BuildArgs / ParseStreamLine / ParseJSONLLine / SessionDir / DiscoverSessions）
  • 将现有 ClaudeAdapter 重构为接口实现
  • 更新 SessionManager 按 agent 类型选择 adapter
  • 更新 watcher 支持多目录监听

改动文件： internal/adapter/adapter.go（新建）、claude.go（重构）、session/manager.go、watcher/watcher.go

1.5.2 Codex Adapter

  • internal/adapter/codex.go（新建）— 解析 NDJSON stdout
  • internal/watcher/codex_watcher.go（新建）— 扫描 ~/.codex/sessions/ 发现终端会话
  • Codex JSONL 文件解析（rollout-*.jsonl）

1.5.3 OpenCode Adapter

  • internal/adapter/opencode.go（新建）— 解析 NDJSON stdout
  • internal/watcher/opencode_watcher.go（新建）— 扫描 XDG_DATA_HOME/opencode/storage/session/
  • OpenCode JSON 文件解析

1.5.4 iOS 适配

  • NewSessionSheet 代理选择器支持 claude-code / codex / opencode
  • Session 列表显示代理类型图标
  • 验证所有代理的 title 生成流程正常工作
2

用户系统 + 多租户

Week 3-5 · 目标：多用户注册，每个用户只看到自己的 Daemon 和 Session

2.1 用户认证系统

  • 数据库新增 users 表（email, password_hash, display_name）
  • 数据库新增 user_daemons 表（用户 ↔ Daemon 绑定 + 别名）
  • Relay 新增 REST API：/api/auth/register、/api/auth/login、/api/auth/refresh
  • JWT 认证中间件（WebSocket + REST）
  • 密码安全：bcrypt hash
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  display_name VARCHAR(100),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

改动文件： relay/src/auth.ts（新建）、relay/src/server.ts、relay/src/router.ts、relay/src/db.ts

2.2 多租户隔离

  • Daemon 注册时绑定用户（JWT 中提取 user_id）
  • listSessions() 按 user_id 过滤
  • 事件推送隔离（session_discovered 等只推给关联用户）
  • daemon_status 只推给该 Daemon 拥有者
  • sessions 表加 user_id 列

改动文件： relay/src/router.ts、relay/src/db.ts

2.3 前端适配

  • 登录/注册页面
  • Token 管理（access_token + refresh_token 自动刷新）
  • 路由守卫（未登录跳转登录页）
  • WebSocket 连接改为 JWT 认证
  • 退出登录

改动文件： useAuth.ts（新建）、useWebSocket.ts、LoginView.vue

2.4 Daemon 认证改造

  • 新增 pocketctl login 子命令（登录获取 JWT 并存储）
  • pocketctl daemon start 使用存储的 JWT 替代 API Key

改动文件： cmd/pocketctl/main.go、internal/ws/client.go

3

移动端 APP + 推送通知

Week 6-8 · 目标：上架 App Store，支持推送通知

3.1 Capacitor 集成（最快上架）

  • 集成 Capacitor 包裹现有 Vue 3 应用
  • 原生能力：@capacitor/push-notifications、@capacitor/local-notifications
  • APP 壳配置：Info.plist 权限声明、App Icon、Launch Screen
  • URL Scheme（pocketctl://）
npm install @capacitor/core @capacitor/cli
npx cap init
npx cap add ios
npx cap add android

改动文件： web/capacitor.config.ts（新建）、web/ios/、web/android/

3.2 推送通知

  • Relay 集成 APNs（iOS）/ FCM（Android）
  • 数据库新增 devices 表（device_token, platform）
  • 推送触发：任务完成、Agent 出错、Daemon 上线/离线

改动文件： relay/src/push.ts（新建）、relay/src/router.ts、relay/src/db.ts

3.3 App Store 上架准备

  • Apple Developer 配置（App ID、推送证书、Provisioning Profile）
  • App Store Connect（名称、描述、截图、分类）
  • 隐私政策 URL、用户协议 URL
  • Demo 账号（供苹果审核）
  • 隐藏未完成功能，确保无 debug 日志
4

订阅付费

Week 9-10 · 目标：Apple IAP 订阅收入

4.1 订阅系统

  • App Store Connect 创建订阅组（免费/个人/专业）
  • Relay 集成 Apple IAP 收据验证（App Store Server API v2）
  • Apple Server Notification V2 回调（自动续订/过期/退款）
  • 数据库新增 subscriptions 表
计划价格功能
免费版¥01 个 Daemon，基础监控
个人版¥18/月无限 Daemon，推送通知，消息发送
专业版¥48/月多人共享，API 访问，优先支持

改动文件： relay/src/subscribe.ts（新建）、relay/src/server.ts、relay/src/db.ts

4.2 Apple 审核注意事项

  • 必须使用 Apple IAP（不能引导用户去网页付费）
  • 必须有恢复购买功能
  • 必须提供隐私政策和用户协议
  • 订阅说明必须清晰（价格、周期、续订规则）
5

生产加固 + 运维

Week 11+ · 持续迭代

5.1 CI/CD

  • GitHub Actions：Go 二进制自动构建（macOS arm64/amd64, Linux）
  • Docker 镜像构建 + 推送（Relay + Web）
  • 自动创建 GitHub Release
  • git tag v0.1.0 触发发布流程

5.2 监控与告警

  • /health 增强（内存、连接数、数据库延迟）
  • 日志结构化（JSON 格式）
  • 腾讯云监控告警（CPU > 80%、内存 > 90%）

5.3 数据安全

  • 数据库自动备份（腾讯云快照）
  • JWT secret 轮换机制
  • 速率限制（防暴力注册/登录）
  • WebSocket 消息大小限制
