设计说明

深色版设计说明：

  • 终端窗口：macOS 三色控件 + 标题栏，直觉传达"终端"含义
  • > 提示符：stroke-width 36，确保 32px 仍可辨识
  • 窗口阴影：纵深感让终端从背景浮出
  • 三色控件：红黄绿提供彩色锚点，黑白主调不显单调
  • 关键元素在圆形裁切安全区（70% 半径）内

白色版设计说明（浅色终端窗口）：

  • 浅色终端窗口：白色/浅灰渐变窗口体 + 浅灰标题栏，整体轻盈通透
  • 深蓝 > 提示符：渐变从 #388bfd → #1f6feb → #0a5dc2，在浅色背景上对比度更高
  • 柔和投影：opacity 0.18，灰色调阴影（非黑色），白色背景上更自然
  • 减弱辉光：stdDeviation 降至 10，opacity 降至 0.25，浅色终端上不需过强辉光
  • 边框加粗：stroke-width 2.5（深色版为 2），浅色窗口边界更清晰
  • 分隔线/边框：统一使用 #d0d7de，GitHub 浅色主题标准灰
  • 适合 GitHub 浅色主题、README、文档站、社交媒体头像
